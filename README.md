
# 🍔 Fast Food Nutrition Analytics

## 📌 Project Overview

This project explores the nutritional composition of menu items from popular fast-food chains using Python.

The objective is to compare restaurants based on nutritional parameters such as calories, protein, fat, carbohydrates, sugar, and sodium using data visualization techniques.

---

## 📊 Technologies Used

- Python
- Pandas
- Matplotlib
- Google Colab

---

## 📈 Visualizations

This project includes:

- Bar Charts
- Horizontal Bar Charts
- Histograms
- Scatter Plots
- Pie Charts
- Box Plots
- Correlation Heatmap
